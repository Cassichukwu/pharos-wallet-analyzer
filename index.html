PHAROS WALLET ANALYZER

An AI Agent Skill for the Pharos Network — Onchain Intelligence at your fingertips

Pharos Pacific Ocean Mainnet

What This Skill Does

🔍

Wallet Analysis

Check any wallet's PROS balance, transaction count and risk signals instantly.

📜

Transaction Explainer

Decode any transaction hash into plain English — type, status, gas cost and more.

⛽

Gas Tracker

Get live gas prices and estimated transaction costs on Pharos Mainnet.

📊

TX History

View recent sent and received transactions for any wallet address.

How to Use

1. Install

git clone https://github.com/Cassichukwu/pharos-wallet-analyzer.git && cd pharos-wallet-analyzer && npm install

2. Analyze a Wallet

node scripts/analyze-wallet.js 0xYourWalletAddress

Returns balance, transaction count, contract detection and risk signals.

3. Explain a Transaction

node scripts/explain-tx.js 0xYourTxHash

Returns transaction type, status, gas cost and plain English explanation.
